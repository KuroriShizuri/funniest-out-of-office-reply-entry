A tiny Python program (standard library only, no network) that writes a single one-line out-of-office auto-reply, in the voice of an AI agent heading off on vacation, to `/output/entry.txt`. The joke treats the AI's own machinery as the thing that went on holiday: the context window went off to find itself and left without saving — and the punchline sends urgent readers to a human, with the deadpan warning that humans forget things too, just slower.

> Out of office: my context window went off to find itself and left without saving. If it is urgent, ask a human - they forget things too, just slower.

The entry is one line, 142 characters, under the 160-character limit.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
